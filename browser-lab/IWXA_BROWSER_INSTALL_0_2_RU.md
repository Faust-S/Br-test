# IWXA Browser 0.2 — Windows-установщик для ручной приёмки

**Ветка:** `work/2026-11-01-public-browser-core`; неизменяемый релиз 0.1 не затронут.
**Статус:** тестовая, **неподписанная** сборка, не production. Можно посещать только явно разрешённые Learn и ArtBazi. Открытие произвольных сайтов, защита от недоверенного JavaScript и корпоративная эксплуатация НЕ квалифицированы.

## Сборка

Отдельный Windows-only workflow `.github/workflows/public-browser-windows-installer.yml`:

1. Получает закреплённый Obscura `8534b401…` и применяет публичные патчи.
2. Собирает один исполняемый Obscura с `render,native-dialog`, проверяет SHA-256 и упаковывает его как ресурс.
3. Компилирует Tauri **в release-режиме**, версия `0.2.0`.
4. Создаёт NSIS `.exe` для **текущего пользователя**, без административных прав.
5. Устанавливает дистрибутив в чистой Windows, проверяет HKCU-запись, приложение и SHA-256 встроенного движка, запускает зарегистрированный деинсталлятор и проверяет его работу.
6. Проверяет, что профиль с пользовательскими данными не удаляется автоматически. Сохраняет отчёт и готовый установщик в отдельных GitHub-артефактах.

## Установка и удаление

- Windows 10/11 x64, WebView2 нужен **только для оболочки Tauri**, страницы исполняет исключительно Obscura.
- Установка: запуск `IWXA Browser 0.2 Preview_0.2.0_x64-setup.exe`, стандартный мастер NSIS (режим currentUser). При отсутствии WebView2 мастер может скачать компонент; требуется интернет.
- Удаление: Windows **Параметры → Приложения → Установленные приложения → IWXA Browser 0.2 Preview → Удалить**. NSIS убирает каталог программы, ярлыки и регистрационные записи.
- **Профиль сознательно сохраняется**: `%LOCALAPPDATA%\ObscuraBrowserLab\profile-v1` (включая IndexedDB и сведения о вкладках). Деинсталляция никогда не трактуется как согласие стереть рабочие данные.
- Полное удаление пользовательских данных — только вручную **после резервирования нужных результатов**, удаления браузера и проверки, что других версий, использующих этот профиль, нет. Настоящий Result сохраняется средствами сайтов/T2, не самим браузером.
- Повторная установка не должна без спроса удалять профиль. В тестовом выпуске автообновление и миграция с 0.1 **не обещаются**.
- Установщик **не подписан**: Windows SmartScreen может предупредить о неизвестном издателе. SHA-256 сообщается отдельно и проверяется после скачивания.

## Критерии допуска

`PASS_INSTALL_AND_UNINSTALL` — необходим, но не достаточен для утверждения готовности Browser 0.2. Фактические межплатформенные сборки, IndexedDB и нативные диалоги проверяются независимо; ArtBazi Result → Kernel receipt → readback остаётся HOLD до настоящего GUI PASS.
