# IWXA Browser 0.2 — измерение визуальной точности

\`compare_frames.py\` измеряет **реальное расхождение двух скриншотов** одинакового размера. Эталон должен происходить из независимо работающего браузера и содержать описание его версии, идентичного размера viewport и DPI, URL, даты и состояния страницы. Для динамических страниц нужно зафиксировать одинаковый DOM/state и отключить или стабилизировать анимацию с обеих сторон.

Показатели: среднее абсолютное отличие RGB, доля существенно отличающихся пикселей (>16 на канал), 95-й процентиль ошибки и ошибка границ (Layout/Text). Верификация контрольных областей и реальных интерактивных действий должна выполняться отдельно: сходство изображения не доказывает работающий JS.

Пример запуска:

\`python browser-lab/benchmarks/compare_frames.py --reference reference.png --candidate obscura.png --provenance reference.json --output fidelity.json\`

**Без явных порогов — только \`MEASURED_NOT_QUALIFIED\`**. Устанавливать пороги после изучения реальных эталонов, а не подгонять их под результат. Нельзя выдавать инструмент, синтетические unit tests и одинаковые картинки за принятую точность реальных сайтов.

Проверка утилиты без зависимости от браузера:

\`python -m unittest discover -s browser-lab/benchmarks -p test_compare_frames.py\`

Набор сайтов для независимой оценки: простая статическая страница с текстом, Flex/Grid, длинная страница с прокруткой и sticky, форма с интерактивностью, несколько сложных публичных SPA. До их запуска и независимого визуального сравнения точность IWXA Browser остаётся HOLD.
