## Выполненная практическая задача

Одноразовый настоящий Git-проект `invoice-demo`. В коде `src/invoice.py` ошибка: процент скидки применяется и к стоимости доставки, хотя требования предусматривают скидку только на товары. Семь независимых тестов, четыре из них исходно FAIL. Aider редактировал только исходник, а тестовая методика не раскрывала модельному исполнителю код правильной правки.

| Критерий | 1.5b | 3b |
|---|---|---|
| Установленный и запускаемый Aider 0.86.0 | PASS | PASS |
| Реальный локальный Ollama model | PASS | PASS |
| Baseline обнаружил ошибку | 4/7 FAIL | 4/7 FAIL |
| Exit Aider CLI | 0 | 0 |
| Изменён реальный исходный файл | **Нет** | **Да** |
| `git diff` | Пустой | Одна точная строка |
| Тесты не изменены | PASS | PASS |
| Post-edit independent unittest | 4/7 FAIL | **7/7 PASS** |
| Возвращаемые суммы по примерам 1250/320/10, 399/49/17, 450/25/100 | Неверны | 1445, 381, 25 |
| Сквозное исправление | **FAIL** | **PASS** |
| Один вызов Aider | 27.898 сек | 32.234 сек |

**Подтверждённая правка 3b:**
```diff
-    discount_cents = (subtotal_cents + shipping_cents) * discount_pct // 100
+    discount_cents = (subtotal_cents * discount_pct) // 100
```

Особенность Aider: в обоих испытаниях CLI вывел сообщение `Applied edit to src/invoice.py` и `returncode:0`; для 1.5b это было **ложное утверждение об успешной правке**. Продукт IWXA не должен принимать текст исполнителя или exit 0 как доказательство изменения кода. Нужны независимые Git diff и тесты.

## Интерпретация

3b продемонстрировала выполнение одной узкой задачи на синтетическом, но реально исполняемом Git-проекте. Это не равно квалификации на крупном публичном репозитории или стабильности при повторах. Смена модели устранила observed FAIL в данной паре экспериментов, но одного теста недостаточно для утверждения о статистически лучшей надёжности модели.

Aider остаётся кандидатом для задач программирования, когда человеку нужен CLI, правка Git и тесты. Запуск отдельной кодовой программы не оправдан для документа/разового API-вызова или когда уже подключённый IWXA executor решает ту же задачу без дополнительной настройки.

**Интеграция с IWXA:** I0 подтверждённое исследование кандидата; I2/I4 NOT_TESTED. Отсутствует адресный адаптер Aider в `AgentRuntimePort` основной ветки; внедрять его следует только после реального пользовательского спроса и сравнения с готовыми Codex/Goose.
