## Граница продукта
Obscura остаётся самостоятельным быстрым headless-инструментом. Видимый Chromium-гость принадлежит хосту, а не модели. Модуль использует оригинальный GuestSession, BrowserControlSession, SessionBrowserController, BrowserCursor, snapshot/actions, MCP-схемы/handlers и automation. Не включать платформу Cherry Studio, её агентов, модельные провайдеры и хранилища. Не заменять существующий IAM/Task/Workspace Agent.

Внутри Electron-процесса API dist/browser-module.mjs:
- VisibleBrowserAdapter(host): хост передаёт WebContents, идентичность, focus/reveal, курсор, разрешения навигации и операций.
- setPresented, setAgentEnabled: только доверенный UI/хост. Уход пользователя отзывает управление, но не уничтожает гостя.
- callTool и execute: оригинальные 20 MCP-инструментов и 20 операций automation; одна последовательная сессия, один tabId, повторная проверка действующего разрешения.
- createBrowserMcpServer / serveBrowserStdio: MCP поверх оригинальных схем, без новой платформы.

Harness является публичным испытательным интерфейсом, не Agent. Одна видимая страница справа, ручная навигация, выдача и отзыв управления, визуальный курсор AI. Native qualification использует настоящий WebContentsView и локальную HTTP-форму; проверяет реальные навигацию, AX-дерево, ввод, select, click, результат, PNG, историю и отказ чужой вкладке/запрещённому execute. Это не испытание установленного Agent.

## Сборка и испытания
Из каталога cherry-browser:
```sh
python verify_vendor.py
npm install
npm run test:all
npm run build
npm run test:native
npm start
```
Для MCP-стенда: npm run start:mcp. На Linux нативное испытание требует графического сеанса (допустим xvfb).
Прямые зависимости закреплены в package.json; транзитивный lock и фактическая сборка требуют доступного npm.
Без нативного исполнения не объявлять готовность.

## Рубеж интеграции
Реальная правосторонняя панель существующего Tauri Agent, её геометрия/фокус/DPI, нативный ввод, профили/авторизация и загрузки/выгрузки должны быть испытаны отдельно. Не подменять их скринкастом или iframe. Привязать передачу управления к существующим правам Agent и его Human Review; действия с внешними последствиями должны проходить действующее согласование. Сохранить 20 исходных инструментов, но не предоставлять execute/WebMCP автоматически. Многовкладочность и восстановление сеанса остаются работой хоста.

Портирование AGPL-кода остаётся AGPL; отдельный процесс сам по себе не гарантирует допустимость совместного распространения с закрытым приложением. До согласования лицензионной модели не включать AGPL-код в закрытый распространяемый продукт.
