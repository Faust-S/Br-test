# Br-test: правила работы в публичном контуре

## GitHub Actions: один осознанный автоматический запуск

Действующее решение владельца 25.11.2026: [единый порядок IWXA](https://github.com/Faust-S/iwxa/blob/knowledge/2026-10-02-system-atlas/knowledge/system/AI_CONTEXT_POLICY_RU.md). Это заменяет исключительно ручной режим и прежний общий запрет одноразовых request-коммитов. Обычные push/PR, изменение workflow, документации, кода, schedule и workflow_run не запускают CI. При реально необходимой операции после собственных проверок агент сам инициирует один прогон точного кандидата. Предпочитать доступный dispatch API; иначе только отдельная ветка `ci/once/<workflow-id>/<prepared-sha>` и единственный новый `.github/ci-requests/<workflow-id>.json`, защищённые двумя фильтрами и проверкой parent/diff/pins до доступа к закрытым источникам. Request-ветка после запуска неизменна; не использовать пустые коммиты, общие триггеры, дубли и автоматические повторения. Перед запуском проверить очередь; один выпускной прогон на линию, concurrency с cancel-in-progress: false. Сохранять полные обязательные проверки, reuse неизменных evidence. Private Actions запрещены; уже специально разрешённый публичный checkout закрытого кандидата не даёт права публиковать его содержимое. Существующие grants не расширять. Для нового необходимого испытания применять этот контракт, не возобновлять архивные workflow ради миграции.
